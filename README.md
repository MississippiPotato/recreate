# 见数 可视化导论交互课程

五课、27 个小节，围绕“先判断 → 看变化 → 讲原因 → 换题用”展开。以大幅图形、分阶段任务和实际操作组织讲解，支持中英文。没有视频。

首页用同一份 80 条记录展示个体、分组与分布，并用 Anscombe 四重奏引出图形的作用。每节先记录预测，再提供观察任务和一键变化；解释阶段回看预测，最后用不同情境的练习检查判断。

“图表诊所”包含坐标截断、无序类别配色和缺失值处理三个病例，读者可以对照原图修复图形。“我的发现”保存自己的解释、预测和实验参数，支持导出 Markdown。记录仅存于当前设备。

## 本地运行

需要 Node.js 20 或更高版本，无需安装运行依赖。

```sh
npm run dev
```

打开终端给出的 `http://127.0.0.1:4174`。修改源码后运行 `npm run build` 并刷新页面。

```sh
npm test
npm run build
```

静态产物为 `dist/`。构建包含首页与 `lesson-01/` 至 `lesson-05/` 五个入口，兼容 `#ch-1-1` 等小节地址。四个阶段可通过 `/step-2` 至 `/step-4` 等片段后缀定位。资源使用相对路径，支持 GitHub Pages 项目子目录。

## 内容与实现

- `src/content.js`：五课讲解、学习目标和中英文练习。
- `src/teaching.js`：预测题、引导操作和每课归纳。
- `src/core.js`：固定种子数据、记录处理、数据匹配、日期映射与等值线计算。
- `src/experiments.js`：D3 实验和独立的比较快照。
- `src/site.js`：导航、目录抽屉、课堂模式与学习笔记。
- `src/home.js`、`src/lesson.js`：首页实验和四阶段讲解台。
- `src/clinic.js`：三个可修复的图表病例。
- `src/experience.css`：深靛蓝首页、浅色学习区和响应式布局。
- `tests/`：核心计算、教学内容和病例数据检查。

原课程：[cinger007/vis](https://cinger007.github.io/vis/)。保留五课、27 小节的课程范围，重新组织讲解与交互。页面不展示教材页码或章节映射。

默认学生、天气、场和事件示例均为标注清楚的教学构造；不作为真实群体统计。Anscombe 四重奏用于说明统计摘要与图形结构的差别。D3 7.9.0 随站点提供，许可证见 `vendor/D3-LICENSE.txt`。色觉模拟为 Machado 等人 2009 年方法的近似辅助预览。

## 验证与发布

关键计算检查、浏览器操作检查和响应式检查用于验证实现。尚未开展计划中的同学学习试用，不能据此宣称学习效果已经提升。

推送 `main` 后，GitHub Actions 执行检查、构建并发布 `dist/` 到 GitHub Pages。教材 PDF、规划文档、截图及临时分析资料不在网站发布包中。
