# 见数 可视化导论交互课程

五课、27 个小节，以“问题—观察—解释—迁移”组织学习。包含同屏讲解与实验、图表数据联动、A/B 比较、等值线分步推导、时间视图切换、课堂模式和中英文内容。没有视频。

## 本地运行

需要 Node.js 20 或更高版本，无需安装运行依赖。

```sh
npm run dev
```

打开终端给出的 `http://127.0.0.1:4174`。修改源码后运行 `npm run build` 并刷新页面。

```sh
npm test
npm run build
```

静态产物为 `dist/`。构建包含首页与 `lesson-01/` 至 `lesson-05/` 五个入口，兼容 `#ch-1-1` 等小节地址。每节讲解步骤可通过 `/step-2` 等片段后缀定位。资源使用相对路径，支持 GitHub Pages 项目子目录。

## 内容与实现

- `src/content.js`：五课讲解、学习目标、中英文练习和参考页序。
- `src/core.js`：固定种子数据、记录处理、数据匹配、日期映射与等值线计算。
- `src/experiments.js`：D3 实验和独立的比较快照。
- `src/app.js`：导航、学习步骤、课堂模式与本地练习记录。
- `src/styles.css`：现代浅色界面、响应式布局与减少动态效果支持。
- `tests/core.test.js`：关键计算和内容完整性检查。

原课程：[cinger007/vis](https://cinger007.github.io/vis/)。课程范围与原有 27 小节对应，重新编写讲解与交互。教材为陈为、沈则潜、陶煜波编著《数据可视化》，页面标注的是参考 PDF 页序。

默认学生、天气、场和事件示例均为标注清楚的教学构造；不作为真实群体统计。Anscombe 四重奏用于说明统计摘要与图形结构的差别。D3 7.9.0 随站点提供，许可证见 `vendor/D3-LICENSE.txt`。色觉模拟为 Machado 等人 2009 年方法的近似辅助预览。

## 验证与发布

关键计算检查、浏览器操作检查和响应式检查用于验证实现。尚未开展计划中的同学学习试用，不能据此宣称学习效果已经提升。

推送 `main` 后，GitHub Actions 执行检查、构建并发布 `dist/` 到 GitHub Pages。教材 PDF、规划文档、截图及临时分析资料不在网站发布包中。
