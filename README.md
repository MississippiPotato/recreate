# 可视化导论 · JavaScript + D3.js

基于[李昕老师的原课程](https://cinger007.github.io/vis/)重构的双语课程网站。五章、27 小节，每节保留 **讲解 / 关键代码 / 演示**。页面正常滚动，章节目录常驻；三个部分可以独立切换，不采用整屏翻步的 PPT 结构。没有视频。

在线地址：<https://mississippipotato.github.io/recreate/>

## 课程内容

| 章节 | 小节数 | 内容 |
| --- | ---: | --- |
| 数据 | 5 | CSV 与类型转换、DIKW、测量尺度与视觉通道、数组操作、选择集与数据连接 |
| 数据可视化流程 | 4 | 流程模型、group / rollup、层次与树布局、HTML 树形列表与事件 |
| 色彩专题 | 8 | RGB/HSL/Lab、三类色板、sRGB 色域切片、五种色系、经典色板、比较与色觉检查 |
| 低维数据可视化 | 5 | 宽长表、比例尺与坐标轴、十种曲线、纵横比、Marching Squares |
| 时序数据可视化 | 5 | 时间属性、折线、日历、周期螺旋、Storyline |

讲解按具体问题、概念关系和案例观察重新组织。修正原材料中按数组长度判断 enter/exit、类别过多改用连续色板、45° 普适规则等不准确表述。保留原站六张数据连接与视觉通道图片，并补充讲义中的 Marching Squares 图示，支持切换与放大。图片来源见 `assets/figures/README.md`。页面不显示教材 PDF 页序或章次对应表。

“关键代码”包含 26 个实际执行的 D3 语法示例，供 27 节使用。显示代码从运行函数提取，含中英文注释、语法说明、可调参数和返回值。注释开关、复制、语法行高亮与 D3 官方文档链接帮助理解选择集、回调、key、比例尺、坐标轴、分组、事件和路径生成器。语法示例为可运行简例；“演示”是各节的完整实验。

演示包含真实 DOM 数据连接与按索引/按 key 比较、CSV 类型转换、10 种数组操作、DIKW、数据流水线、可展开的 HTML 树形列表与冒泡日志、配色库与同数据比较、10 种曲线与最小二乘直线对照、16 种等值线状态和四角编辑、共享日期的时间视图。标签切换和中英文切换保留当前实验参数。图表诊断作为补充案例保留。

首页的五种粒子图形为本项目编写的 Canvas 动画。参考站仅用于设计研究；未复制其粒子源码、足球、纸质背景或其他素材。字体与 D3 均在本地加载。小屏使用目录抽屉，支持 Ctrl/Cmd K 搜索概念与 API、标签键盘导航、正文放大与演示区放大。

## 本地运行

需要 Node.js 20+，无需安装 npm 运行依赖。

```sh
npm run dev
```

打开 <http://127.0.0.1:4174/>。修改源码后执行 `npm run build` 并刷新。

```sh
npm test
npm run build
```

构建生成 `dist/`，包含首页与 `lesson-01/` 至 `lesson-05/` 入口。兼容 GitHub Pages 子目录。路由示例：

- `#ch-1-5`：数据连接讲解。
- `#ch-1-5/code`：关键代码。
- `#ch-1-5/demo`：完整交互演示。
- `?lang=en#ch-4-5`：英文等值线讲解。
- `#clinic`：补充诊断案例。

旧版 `/step-2` 地址兼容跳到演示，其他旧阶段跳到讲解；`?mode=lecture/study` 不再改变页面形态。

## 源码与讲义

- `src/main.js`：三标签课程、导航、代码运行、图片查看与搜索。
- `src/course-data.js`：重新组织的中英文讲解、原图和观察任务。
- `src/code-labs.js`：带双语注释的运行函数和语法说明。
- `src/interactive.js`：新交互案例、真实数据连接与事件列表。
- `src/experiments.js`：D3 图形、参数、对照与等值线实验。
- `src/core.js`：确定性数据和核心计算。
- `src/course.css`：页面、导航、代码、实验与响应式 CSS。
- `src/intro.js`：原创粒子动画与清理逻辑。
- `src/content.js`、`src/teaching.js`、`src/lecture-content.js`：共享案例、练习和演示预设数据；已移除旧的幻灯片页面入口。
- `scripts/export-handouts.mjs`：从相同讲解与运行函数生成双语 Markdown 讲义。构建自动执行，输出至 `assets/handouts/`；侧栏可下载当前章节。
- `vendor/fonts/`、`vendor/d3.min.js`：本地字体子集与 D3 7.9.0，附相应许可证。

学生记录为固定种子 42 的 80 条合成样本。2024 年逐日气温含缺失值；周期示例有独立的生成周期；Storyline 为虚构考察队。数据用于教学，不作为真实世界统计结论。未添加视频或播放器。

## 检查与发布

`npm test` 的 21 项检查覆盖数据身份、聚合、变换、日期、周期、最小二乘模型、等值线 16 状态和歧义处理等。浏览器检查需分别覆盖三标签、中英文、运行代码的结果、交互行为、图片资源与窄屏溢出。通过构建或截图不代表完成真实课堂学习效果试验。

推送 `main` 后 GitHub Actions 检查、构建并发布 `dist/`。原始教材 PDF、工作计划、浏览器截图和临时分析不进入发布包；课程用到的原图和优化后讲义保留。
