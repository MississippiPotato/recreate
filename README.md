# 可视化导论 · JavaScript + D3.js

基于[李昕老师的课程](https://cinger007.github.io/vis/)重构的双语教学网站。五章、27 小节，整章连续阅读。每节左侧保留完整讲解和可展开的关键代码，右侧常驻交互画布。讲解、代码与图形可以同时对照，没有视频。

在线地址：[mississippipotato.github.io/recreate](https://mississippipotato.github.io/recreate/)

## 课堂中的用法

进入章节，先看到完整图形与配套讲解。核心案例可以从第一步重放，或用左右箭头逐步查看：数据、映射、编码与最终图形。步骤改变时，对应的代码段展开并高亮；代码段上的“在图中查看”可以反向定位到画布状态。普通参数操作、完整绘制函数和原有实验也保留在画布中。

27 节的原有讲解、分类表、原图和案例说明全部保留。原来的 58 段双语代码及“关键点解释”保留，新增 8 段讲解数据块过渡、成对配色、CVD 矩阵、Crime 1985、十曲线叠加、平均倾角、完整等值线与卷曲插值。共 66 段代码，每段可复制；另有 27 个可运行的 D3 语法示例。

全屏展示整个小节，讲解和画布仍同屏。退出返回原阅读位置，保留步骤、参数和绘制节点。Ctrl/Cmd K 可以搜索讲解、代码注释、关键点解释、演示与步骤名称；结果直接定位到标题、代码段或画布。旧 `/code` 和 `/demo` 链接仍然有效，分别定位页面中的代码和演示区域。

## 五章案例

| 章节 | 内容与交互 |
| --- | --- |
| 01 数据 | CSV 数值块与类型转换、DIKW、测量尺度与视觉通道、filter/map/group/rollup 动画、按索引与按 key 的真实 DOM 对照 |
| 02 可视化流程 | 二维数据表、JSON 层次、布局坐标与树连边逐层构建；保留分组和可折叠 treelist、事件冒泡日志 |
| 03 色彩 | RGB/HSL/Lab、色域、三类色板；5–7 色鲜艳/低饱和成对生成器；散点、热图和红绿柱图的三种色觉对比及冗余编码 |
| 04 低维数据 | Crime 1985 宽长表、性别差比例、散点与平行坐标；十种曲线同数据叠加；Cardinal 越界与 MonotoneX 对比；平均绝对倾角计算；完整二维地形与单格 16 态联动 |
| 05 时序数据 | 时间属性、折线、日历与 Storyline；84 个观测点通过连续滑块从直线坐标卷成阿基米德螺旋，可独立改变每圈天数 |

15 个核心小节提供四步推演，其余小节保留原有参数交互和演示预设。图表诊断直接嵌入各章，展示常见画法与修复后的对照；独立的 `#clinic` 入口也保留。

首页以原课程的 80 条新生 CSV 记录串起五章：原始字段与类型转换 → 月份分组与位置映射 → 彩虹/顺序配色与色觉对比 → MonotoneX、密度等值线与倾角调整 → 生日时间轴到按年周期的螺旋。所有阶段保留同一批记录的编号，支持逐章点击与连续播放。

数据与算法参考见 [assets/data/SOURCES.md](assets/data/SOURCES.md)。原图来源见 [assets/figures/README.md](assets/figures/README.md)。D3 和字体均从本地文件加载。

## 本地运行

需要 Node.js 20+，无需安装 npm 运行依赖。

```sh
npm run dev
```

打开 <http://127.0.0.1:4174/>。源码更新后执行 `npm run build` 并刷新。

```sh
npm test
npm run build
```

构建输出 `dist/`，同时生成 `lesson-01/` 至 `lesson-05/` 入口，兼容 GitHub Pages 子目录。

常用链接：

- `#lesson-1`：第一章与常驻画布。
- `#ch-1-5`：数据连接的索引/key 对照。
- `#ch-3-7`：成对配色生成。
- `#ch-4-3`：十种曲线。
- `#ch-4-5`：完整等值线与单格联动。
- `#ch-5-4`：折线/螺旋连续卷曲。
- `#ch-2-2/code/keycode-0`：打开并定位聚合代码，联动对应画布步骤。
- `?lang=en#ch-4-5`：英文等值线。
- `#clinic`：独立图表诊断。

## 源码与讲义

- `src/main.js`：连续课程、完整讲解、代码折叠与双向联动、全屏、导航、图片查看和搜索界面。
- `src/learning-studio.js`、`src/lesson-steps.js`：每节的步骤状态、播放、代码对应与原有实验入口。
- `src/visual-labs.js`：数据块、真实数据连接、树布局、成对配色、色觉图测、曲线、倾角、完整等值线、Crime 多视图和卷曲画布。
- `src/data-journey.js`：首页同数据五章演示。
- `src/visual-math.js`：可独立验证的倾角、卷曲、配色与色觉计算。
- `src/source-data.js`：原课程 CSV 加载与缓存。
- `src/reading-notes.js`：原有完整双语讲解与表格。
- `src/code-guide.js`：66 段双语代码及关键点解释。
- `src/code-labs.js`：27 个可运行语法示例。
- `src/interactive.js`、`src/experiments.js`、`src/core.js`：原有交互、参数、数据与计算。
- `src/course-search.js`、`src/course-navigation.js`：内容检索、精确定位和旧路由兼容。
- `src/course.css`、`src/chapter.css`、`src/studio.css`：基础样式、章节、同屏画布、全屏和响应式布局。
- `scripts/export-handouts.mjs`：从相同正文与代码生成中英文 Markdown 讲义，侧栏可下载。
