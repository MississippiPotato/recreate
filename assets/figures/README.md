# Course figures

The following six images are retained from the original course repository,
https://github.com/cinger007/vis (local source revision `35a66ec`):

- `data-join.png`: `lesson-01/data/join.png`.
- `01-mackinlay-ranking.png` through `05-identity-channels.png`:
  `lesson-02/img/` with the same filenames.

`marching-squares-16.png` is a cropped rendering of Figure 5.6 from the supplied
Chen Wei visualization textbook. Its source is documented here for maintenance;
the course interface does not display textbook page-number or chapter mappings.

The original figures are used as teaching references, with bilingual captions and
an enlargement control. New homepage particle artwork and course thumbnails were
implemented specifically for this reconstruction; reference-site artwork and
backgrounds were not copied.
